# Test_Data 숙소 영상 제작 계획

**목표:** 사진 17장과 Fish Audio 일반여성2(ID: 4a81bbbb5cd44f22922bf934cb93b369)로 참고 영상 스타일의 세로 MP4를 제작한다.

**실행:** 사용자가 영상 제작을 명시적으로 요청했다. 현재 세션에서 직접 제작하고 검증한다. 음성 복제는 필요 없다.

**구성:** 사진 검토 → 장면별 대본·음성 → 음성 길이 기반 편집 → 중앙 자막 → 1080×1920 MP4. 사진 원본은 보존한다. 숙소 이름·가격·온천 여부·조식 포함 여부 등 확인되지 않은 정보는 넣지 않는다.

- [x] 사진 17장과 참고 영상의 기존 장면 캡처를 확인한다.
- [x] 공개 목소리 일반여성2를 조회해 정확한 ID를 확인한다.
- [x] FFmpeg를 프로젝트 .tools/python에 준비하고 참고 MP4를 디코딩해 장면을 재확인한다.
- [x] 10개 짧은 내레이션을 생성해 장면별 결과를 output/audio에 보관한다.
- [x] scripts/render_video.py에서 사진 크롭·완만한 확대·중앙 흰색 자막과 검은 외곽선을 구현한다. 각 장면의 길이는 실제 음성 길이로 정한다.
- [x] 모든 사진을 순서에 맞춰 배치하고 MP4와 SRT, 대본 JSON을 저장한다.
- [x] 전체 영상을 끝까지 디코딩하고 해상도·오디오·길이·자막 및 주요 프레임을 검증한다.

완료 기록: 24.5초, 1080×1920, 30fps, 735프레임. 전체 디코딩·음성 스트림·17개 사진 사용·타임라인 검사 통과. 실제 출력 장면 10개를 추출해 자막과 사진 배치를 확인했다. unittest 2개 통과. 독립 읽기 검토에서도 중요 결함이 발견되지 않았다. 음성을 직접 청취한 검증은 하지 않았다.

**검토 항목:** 가로 사진의 과도한 크롭, EXIF 회전, 한글 자막 잘림, 음성 끝 잘림, 짧은 장면에서 여러 사진이 지나치게 빨리 전환되는 문제. 가로 사진은 원본을 크게 유지하고 뒤에 흐린 배경을 배치한다. 사진당 최소 0.9초를 확보한다. 음성보다 장면이 길면 남은 구간을 짧은 여백으로 처리한다.

**산출물:** output/stay_reel.mp4, output/stay_reel.srt, output/storyboard.json, output/preview.jpg 및 재실행 가능한 로컬 합성 스크립트. 음성 생성 실패는 자동 재호출하지 않고 성공 결과를 보존한다.
