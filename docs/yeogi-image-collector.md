# 여기어때 숙소 이미지 수집기

국내 숙소 상세 링크 목록에서 숙소 갤러리·객실 사진을 수집한다. 리뷰 사진은 수집하지 않는다. 조회 시점의 상세 페이지 데이터에 포함된 객실만 대상으로 하므로 사이트 전체 객실 목록을 보장하지 않는다.

## 실행

Stay Studio에서도 **숙소 링크로 사진 가져오기 → 이미지 수집 → 사진 선택 → 선택한 사진 추가**로 사용할 수 있다.
프로그램 수집 결과는 개발 시 `.local/collections`, 배포 시 `%LOCALAPPDATA%\StayStudio\collections`에 저장한다.
숙소명·객실명·사진 제목을 표시하며 선택 사진과 기존 첨부 사진을 합쳐 최대 60장을 사용한다.
사진 목록 추출·URL 검증·원본 파일 검증은 `studio/yeogi.py`를 터미널 수집기와 프로그램이 공유한다.
아래 명령은 기존 터미널 수집 방법이다.

현재 프로젝트 Python 환경에는 Playwright, Pillow와 Chrome이 설치되어 있다. 프로젝트 루트에서 실행한다.

```powershell
& 'C:/Users/qasd1/.pyenv/pyenv-win/versions/3.11.9/python.exe' scripts/collect_yeogi_images.py
```

실행하면 터미널에 `숙소 링크 1>`이 표시된다. 국내 상세 주소(`https://www.yeogi.com/domestic-accommodations/숙소ID`)를 붙여 넣고 Enter를 누른다. 다른 숙소도 수집하려면 다음 링크를 입력한다. 모두 입력했으면 아무것도 입력하지 않고 Enter를 한 번 더 눌러 수집을 시작한다.

```text
숙소 링크 1> https://www.yeogi.com/domestic-accommodations/9816
숙소 링크 2> [아무것도 입력하지 않고 Enter]
```

잘못된 링크나 중복 숙소는 안내 후 다시 입력받는다. 링크 없이 끝내면 파일을 만들거나 브라우저를 열지 않고 종료한다. 입력 중 Ctrl+C를 누르면 수집하지 않고 취소한다.

기존 파일 입력 방식도 사용할 수 있다. UTF-8 `urls.txt` 파일을 만들고 `--urls urls.txt`로 실행하면 터미널 입력 없이 바로 수집한다. 파일에서는 빈 줄과 `#` 주석을 무시한다. 같은 숙소 ID는 최초 링크만 처리하며 날짜 등 쿼리 매개변수는 유지한다. 파일의 해외·검색·다른 사이트 주소는 실패 목록에 기록한다.

다른 환경에서는 `python -m pip install -r requirements-collector.txt`로 의존성을 설치한다. Chrome이 없으면 `python -m playwright install chromium`으로 브라우저도 설치한다.

기본값은 브라우저 창 표시, 요청 간격 1초다. 창은 수집 종료 시 닫힌다. `--headless`로 창을 숨길 수 있으나 사이트가 차단할 수 있다. `--interval`은 최소 0.5초, `--output`은 다른 결과 폴더 지정에 사용한다. 동시에 같은 결과 폴더를 사용하는 수집기를 여러 개 실행하지 않는다.

## 결과

- `Data/accommodations/<숙소ID>/images/`: 원본 이미지 파일. SHA-256 해시를 파일명으로 사용해 내용이 같은 사진을 하나만 저장한다. 확장자는 실제 이미지 형식에 맞춘다. 크롭·리사이즈·형식 변환을 하지 않는다.
- 숙소별 `manifest.json`: 숙소명·출처·수집 시각과 사진별 URL, 제목, 객실명, 파일 경로, 해상도, 해시, 실제 형식, 재사용 여부, 실패 기록. 같은 파일의 여러 출처 URL은 개별 항목으로 남긴다. `file` 경로는 해당 숙소 폴더 기준이다.
- `Data/accommodations/collection_report.json`: 링크별 결과와 오류를 담은 실행 보고서. 가장 최근 실행으로 갱신한다.

상태는 `complete`(전체 성공), `partial`(일부 사진 실패), `failed`(페이지 또는 모든 사진 실패), `invalid`(입력 링크 오류)로 구분한다. 처리 중인 manifest는 `in_progress`다. 일부 실패가 있어도 다음 숙소를 처리한다. 모든 링크가 성공하면 종료 코드 0, 실패·잘못된 링크가 있으면 1, 입력 파일·명령 인자 오류는 2다.

같은 목록으로 재실행하면 파일의 실제 내용과 해시를 검사해 정상 파일을 재사용하고 실패·손상된 파일은 다시 다운로드한다. 이전에 받은 사진은 자동 삭제하지 않으며, 현재 조회에서 찾은 사진은 최신 manifest를 기준으로 확인한다. 페이지 조회가 실패하면 기존 이미지 항목을 보존하고 페이지 오류를 기록한다.

Windows에서 파일 교체가 일시적으로 거부되면 최대 5회 재시도한다. 지속적인 권한 오류는 실패로 남기며 기존 기록 파일을 먼저 지우지 않는다.

숙소 페이지는 브라우저로 읽고 이미지 파일만 직접 요청한다. 통신 시간 초과와 429·일부 5xx 응답은 최대 2회 재시도한다. 403, 추가 인증 화면, 사진 목록 누락·구조 변경은 오류로 기록한다. 로그인이나 차단 우회는 구현하지 않는다. 브라우저를 종료하거나 실행을 중단해도 이미 저장한 파일은 남는다.

영상 작업에는 숙소별 `images` 폴더를 전달하고, 제목·객실명·출처 확인이 필요하면 manifest를 함께 사용한다. 기존 영상 렌더러의 입력 경로를 자동으로 바꾸지는 않는다.
