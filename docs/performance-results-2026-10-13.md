# 숙소 숏폼 병렬 처리 개선 — 2026-10-13

기존 저장 미디어로 측정한 로컬 합성은 222.615초에서 177.068초로 줄었다(45.547초, 약 20.5% 단축). 첫 개선 측정은 172.006초였다. 재측정 완성 MP4와 변경 전 완성 MP4의 SHA-256이 같아 이 입력의 영상 결과는 바이트 단위로 동일했다.

이 문서는 병렬 처리 개선 당시의 측정 기록이다. 이후 추가한 음성O 프레임 보간과 컷 연결 개선에는 이 시간·해시 비교가 적용되지 않는다. 아래 측정 산출물 링크는 로컬 작업 폴더용이며 영상·음성 산출물은 이번 소스 커밋에 포함하지 않는다.

## 적용 내용

- `고화질 + 대본 함께 만들기`: 사진 변환과 원본 사진 기반 대본 분석을 동시에 시작한다. 현재 UI는 이 버튼 하나로 통합되었으며 새 작업의 다음 단계 버튼에서도 동시 준비를 안내한다.
- 분석 스냅샷은 사진 변환 결과를 덮어쓰지 않는다. 변환 결과를 다시 읽은 뒤 대본만 병합한다. 이미 세로 1080×1920인 변환본의 크롭 좌표는 중앙으로 맞추며, 실패해 원본을 쓰는 사진에는 원본 분석 좌표를 유지한다.
- 동시 분석 프롬프트는 제거될 사람의 존재·행동과 주변부 디테일에 의존하지 않도록 지시한다. AI 결과 품질은 실제 작업에서 확인해야 한다.
- 음성은 작업당 최대 3개가 동시에 진행된다. Drama의 변경·제출 잠금은 유지하고, 음성 완료 조회와 다운로드는 잠금 밖에서 진행한다. 같은 음성 자산은 한 번만 생성한다.
- 움직임 영상은 최대 3개씩 상태 확인·다운로드한다. 한 클립 실패 시에도 다른 제출 작업의 결과를 저장한 뒤 오류를 표시한다. 기존 요청 ID와 음성 복구 참조를 재사용한다.
- FFmpeg 클립은 2개씩 합성한다. 각 필터 그래프 스레드도 2개로 제한한다. 인코딩 옵션과 전체 출력 검사는 유지한다. 모든 클립이 끝난 뒤 순서대로 묶는다.
