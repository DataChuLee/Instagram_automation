# 숙소 영상 자동화 제안

상태: 초기 제안의 기록. 2026-10-08 사용자가 일반여성2 공개 목소리와 Data/Test_Data 사진 17장을 지정하고 영상 제작을 요청했다. 목소리 복제 대신 지정 목소리로 제작한다. 실제 제작 계획은 `docs/superpowers/plans/2026-10-08-test-data-video.md`, 최신 진행 상태는 `CONTINUE.md`를 따른다.

## 목표와 입력

숙소 사진과 선택적인 숙소 설명으로 동일한 목소리의 한국어 내레이션과 동기화 자막이 들어간 인스타그램용 세로 MP4를 만든다. 시설·위치·가격 등은 제공된 설명으로 확인하며 사진만 보고 추측하지 않는다.

첫 결과물은 약 25~30초, 1080×1920, 30fps로 제안한다. 실제 발화 길이에 맞춰 조정한다. 입력은 사진 폴더, 숙소 설명, 재사용할 목소리 ID다. 현재 Data에는 참고 영상 2개와 음성 샘플만 있고 숙소 사진은 없다.

## 확인한 참고 스타일

저장된 참고 영상 장면 이미지 2장을 직접 확인했다. 중앙 부근의 짧은 흰색 굵은 자막과 검은 외곽선을 사용한다. 시작 문구로 관심을 끌고 공간별 특징을 짧게 소개한다. 실제 오디오를 청취 분석한 것은 아니므로 목소리 톤·속도 일치 여부는 생성 샘플을 사용자가 들어보고 판단한다.

## 방식 비교

1. **추천: Codex + Fish MCP + 로컬 영상 합성.** 현재 OAuth와 웹 플랜을 활용한다. Codex가 사진과 설명으로 대본을 만들고 MCP로 음성을 생성하며, 로컬 Python 프로그램이 장면·자막·음성을 합친다. 첫 단계는 대화에서 실행하는 자동화이며 무인 예약 실행은 별도 범위다.
2. **별도 개발자 API 기반 무인 실행.** 예약·일괄 실행에 적합하지만 개발자 API 인증과 비용 구성이 추가된다. MCP의 웹 플랜 잔액과 개발자 API 잔액을 혼용하지 않는다.
3. **Fish의 생성형 영상.** 추가 모델 비용과 견적 승인이 필요하다. 실제 숙소 사진의 시설 형태를 유지하는 첫 결과물에는 로컬 사진 합성을 추천한다.

## 추천 흐름과 구성

- 사진·설명을 검토해 장면별 대본을 JSON으로 저장한다. 각 장면은 사진 경로, 내레이션 문장, 자막 문구를 갖는다. 사용자가 대본을 고칠 수 있게 한다.
- 샘플 목소리 사용 권한을 확인한 뒤 비공개 목소리를 생성하고 ID를 저장한다. 기존 TTS 목소리라면 원래 서비스와 ID를 먼저 확인한다. 매 영상마다 복제를 반복하지 않는다.
- 처음에는 짧은 대본 한 개로 목소리를 검토한다. 확정 후 장면별 음성을 같은 ID로 생성하고 결과를 저장한다. 기존 결과를 재사용하며 재시도로 중복 비용을 내지 않도록 한다.
- 장면별 오디오 길이를 측정해 장면과 문장 자막 시간을 맞춘다. 자막은 문장 전체를 해당 음성 구간 동안 표시하는 방식부터 구현한다. 단어별 정렬은 초기 범위에 포함하지 않는다. 긴 문장은 대본 작성 단계에서 짧은 장면으로 나눈다.
- 사진에는 완만한 확대·이동을 적용하고 중앙 자막을 넣는다. 사진별 크롭 위치를 수정할 수 있게 한다. 배경음악은 제공된 사용 가능 음원이 있을 때 추가한다.
- Python 렌더러는 대본 JSON과 오디오 파일을 입력받아 FFmpeg로 MP4와 SRT를 출력한다. 대본 생성·Fish 호출은 Codex에서 담당해, 로컬 렌더러가 OAuth 토큰이나 API 키를 직접 다루지 않도록 한다.

## 검증과 실패 처리

입력 누락과 잘못된 경로는 외부 생성 전에 검출한다. FFmpeg/FFprobe 실행 가능 여부, 필요한 코덱·한글 폰트를 확인해야 한다. 현재 PATH에는 FFmpeg/FFprobe가 없으며 설치는 아직 하지 않았다.

장면별 오디오와 생성 기록을 보존해 실패한 단계부터 재개한다. 생성 결과를 받지 못한 요청은 자동으로 반복하지 않는다. 출력 검증은 해상도, 음성 포함 여부, 오디오·영상 길이, 자막 시간 범위와 한글 표시를 확인한다. 최종 품질은 미리보기 영상으로 사용자가 확인한다.

## 진행 전 확인할 사항

1. 음성 샘플이 본인 목소리이거나 화자의 복제·홍보 사용 동의를 받았는지 확인한다. Fish 복제 도구의 필수 확인 항목이다.
2. 추천 방식과 첫 결과물 범위를 검토한다. 확정 후 상세 설계·구현 계획을 작성한다.
3. 실제 숙소 사진과 설명을 준비한다. 사진이 없을 때 참고 영상을 실제 숙소 입력으로 간주하지 않는다.
