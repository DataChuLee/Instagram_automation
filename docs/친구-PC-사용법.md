# Stay Studio — 친구 PC 사용법

Windows 10/11 64비트에서 사용합니다. 인터넷 연결, ChatGPT 구독 계정,
Fish 패키지 크레딧이 필요합니다. 개발자 API 키를 입력하는 프로그램이 아닙니다.

## 실행

1. `StayStudio-Windows.zip`을 압축 해제합니다. 폴더 전체를 유지하세요.
2. `StayStudio.exe`를 실행합니다. 브라우저에 `http://127.0.0.1:8765`가 열립니다.
3. **계정 연결**에서 ChatGPT/Codex 구독 계정과 Fish MCP를 연결합니다.
   Codex는 공식 브라우저 로그인입니다. 브라우저가 자동으로 열리지 않으면
   **ChatGPT 로그인 화면 열기** 링크를 누르세요.
   Fish MCP는 브라우저 OAuth 로그인으로 한 번 연결합니다. 같은 연결로 움직임과
   Drama3 음성을 생성하므로 별도 음성 로그인 창은 필요하지 않습니다.
4. 사진을 첨부하거나 **숙소 링크로 사진 가져오기**에 여기어때 국내 숙소 상세 링크를 넣고
   **이미지 수집**을 누릅니다. 수집이 끝나면 원하는 사진을 골라 **선택한 사진 추가**를 누르세요.
   파일 첨부와 링크 사진을 함께 쓸 수 있습니다. 숙소명과 출처도 작업에 저장됩니다.
   영상에 넣는 사진은 최대 60장, 사진당 20MB, 선택 사진 전체 300MB, 짧은 변 300px 이상입니다.
   후보 사진은 직접 첨부했거나 수집 목록에서 골라 가져온 사진만 들어갑니다.
   고르지 않은 수집 사진은 후보와 AI 추천에 쓰이지 않습니다.
   **직접 구성**은 선택한 순서를 유지합니다. 사진을 끌거나 화살표로 순서를 바꾸고
   **사진 분석 & 대본 만들기**를 누르세요. **AI 추천 구성**은 후보 사진 안에서 원하는
   장수(기본 10장, 1~60장)의 사진·순서·이유·대본·움직임을 함께 추천합니다.
   수집 목록에서 체크한 사진이 있으면 그 사진도 후보에 더한 뒤 추천합니다.
   분석 후에도 후보를 추가할 수 있습니다. 후보로 구성을 교체하면 대본을 다시 작성합니다.
   필요 없는 후보는 체크한 뒤 **선택한 사진 후보에서 제거**를 누르세요.
   현재 영상에 쓰이는 사진은 구성을 바꾼 뒤에 제거할 수 있습니다.
   분석 전에 **고화질 변환 · 인물 제거**를 누르면 Codex가 사진을 세로 9:16 고화질로 다시 만들고
   사람과 모자이크를 지우며 밝고 화사하게 보정합니다. ChatGPT 구독 사용량을 쓰며 10장에 약 3분 걸립니다.
   변환된 사진에는 HD 표시가 붙고, 사진 아래 **HD/원본** 버튼으로 사진마다 원본으로 되돌릴 수 있습니다.
   결과가 어색하면 **↻**로 그 사진만 다시 변환하세요. 가로로 넓은 사진은 위아래를 AI가 새로 그리므로
   실제 숙소와 다르게 보이지 않는지 미리보기로 확인하세요.
5. 상단의 제작 순서와 다음 행동 버튼을 따라 진행하세요. 스크롤해도 진행 상태와
   오류 안내가 상단에 남습니다. 제작 순서를 누르면 해당 편집 영역으로 이동합니다.
   필요하면 대본을 수정하고 **변경 사항 저장**을 누르세요. 대본이 그대로 화면 자막이 됩니다.
   대본·움직임·자막 설정을 한 번에 저장합니다. 저장하지 않은 변경이 있으면
   새 작업·이전 작업 이동·페이지 종료 전에 확인합니다.
   사진을 선택하면 **선택한 사진** 미리보기에서 자막·크롭을 바로 확인합니다.
   **생성된 영상**을 누르면 저장된 영상의 움직임과 내레이션을 확인합니다.
   **자막 위치·색상·음성 속도 설정**을 펼쳐 세부 설정을 조절하세요.
   기본값은 페이퍼로지 Bold, Y=13입니다.
   글자 크기와 X/Y 위치는 슬라이더 옆 숫자로도 입력할 수 있습니다.
   글자 크기는 28~120의 정수, X/Y는 -35~35의 0.5 단위입니다.
   **사진 움직임 설정**을 펼쳐 AI 추천을 바꾸거나 원하는 사진만 체크하세요. 수동 선택은
   개수 제한 없이 업로드한 사진 전체를 선택할 수 있습니다. 예를 들어 사진 2·3만 선택하면
   두 사진만 움직이고 나머지는 정지 사진입니다. 자동 추천은 적합한 사진만 최대 3장입니다.
   선택한 사진마다 프롬프트를 따로 입력할 수 있으며 한국어·영어를 그대로 사용합니다.
   **변경 사항 저장**으로 저장하세요. 견적 요청 시 미저장 변경도 먼저 저장됩니다.
   음성과 화면 자막은 같은 대본 문장을 사용합니다. **선택한 사진의 세로 크롭**에서 피사체 중심을
   조절할 수 있습니다. 생성 진행 중이거나 제출 결과가 불확실한 동안에는 수정을 잠급니다.
   내레이션 수정은 해당 음성만, 움직임 프롬프트·크롭 수정은 해당 움직임만 새 견적을 받습니다.
6. 필요하면 **영상 모델**을 펼쳐 **모델별 화질·크레딧 비교**를 누르세요. 내 사진 1장으로
   각 모델의 무료 견적을 조회해 화질(720p~1080p)과 움직임 1장당 크레딧을 보여 줍니다.
   720p·768p 모델의 결과는 1080×1920으로 확대해 합성합니다. 기본 모델은 seedance-2.0 1080p입니다.
   모델을 바꾸면 움직임은 새로 견적을 받고, 예전 모델로 되돌리면 이미 만든 움직임을 다시 씁니다.
   **크레딧 견적 확인**을 누릅니다. 움직임과 음성의 실제 견적을 확인한 뒤
   **이 금액 사용 승인 & 영상 만들기**를 눌러야 유료 생성이 시작됩니다.
7. 생성이 끝나면 AI 움직임·음성·자막을 포함한 **1080×1920, 30fps 영상 미리보기**에서
   재생·탐색·볼륨을 확인합니다. **확인한 영상 내보내기**를 눌러 결과물을 저장하세요.
   미리보기와 최종 영상은 동일한 영상 파일을 사용하며 내보내기에 새 Fish 호출은 없습니다.
   **완성본**은 자막·내레이션 포함 MP4,
   **영상**은 자막·음성 없는 MP4, **자막대본**은 TXT 및 시간 자막 SRT,
   **음성파일**은 영상 순서와 속도에 맞춘 내레이션 MP3입니다.
   자막·속도·사진 순서만 바꿀 때는 **변경 내용을 영상에 반영**을 사용하세요.
   음성을 재사용하므로 추가 생성 크레딧을 사용하지 않습니다. 장면 사이로 사진을 옮기면
   기존 장면의 음성·자막은 유지한 채 사진 배치를 바꿉니다. 사진과 문구가 맞는지 확인하세요.
   **이 음성/움직임 다시 생성**은 같은 설정도 새 결과를 요청하도록 표시하며, 견적 승인 후
   생성합니다. 이전 결과 플레이어와 **결과 복원**, **이전 구성 복원**으로 되돌릴 수 있습니다.
   변경 전 영상은 오래된 미리보기로 표시하고 최신 미리보기가 준비될 때까지 내보내기를 막습니다.

## 영상과 움직임

- 출력은 항상 1080×1920, 9:16, 30fps, H.264 MP4입니다.
- 가로 사진은 피사체 중심으로 세로 크롭합니다. 원본 사진 해상도가 낮으면
  원본에 없는 디테일을 복원하는 효과는 없습니다.
- 움직임은 Fish MCP의 Seedance 2.0, 네이티브 1080p, 4초로 요청합니다.
  AI 추천 기본값은 최대 3장이고, 사용자가 업로드한 사진 전체를 움직임으로 선택할 수 있습니다.
  실제 반환 해상도가 다르면 출력하지 않습니다.
- 적합하지 않은 사진은 움직임 생성 대신 부드러운 확대를 적용합니다.
  생성 클립보다 장면이 길면 마지막 프레임을 유지하며 반복 재생하지 않습니다.
  긴 화면 자막은 최대 두 줄씩 나누어 표시합니다. 실제 길이 25~35초, 사진당 평균 1.5초,
  마지막 사진 1초 기준을 벗어나면 편집 화면에 권장사항을 표시합니다.
- 음성은 일반여성2(ID `4a81bbbb5cd44f22922bf934cb93b369`), Drama3입니다.
  Fish MCP 안의 Story Studio를 사용하며 모델은 `drama-3-preview`로 고정합니다.
- 무료 견적을 확인하고 승인한 뒤 음성을 생성합니다. 모델·목소리·대본·가격이
  변경되면 생성하지 않고 이유를 표시합니다.
- Y=13은 첨부 화면을 기준으로 화면 중앙보다 13% 위, 즉 1920px 화면에서 약710px입니다.
  VLLO의 내부 좌표 규격을 가져온 것은 아니므로 프로그램 미리보기로 최종 위치를 확인하세요.

## 중단된 작업

링크 수집은 `%LOCALAPPDATA%\StayStudio\collections`에 저장됩니다.
수집용 브라우저 창이 열리고, 수집이 끝나면 닫힙니다. 수집 중에는 해당 창을 유지하세요.
수집을 중단했으면 같은 링크로 다시 수집하세요. 정상 저장된 원본 사진은 재사용합니다.
일부 사진 수집이 실패해도 성공한 사진을 선택해 작업에 넣을 수 있습니다.
현재 링크 수집은 여기어때 국내 숙소 상세 페이지를 지원합니다.
해외 숙소·검색 페이지·다른 사이트 링크는 지원하지 않습니다.
수집 화면에 해상도나 용량 때문에 사용 불가로 표시된 사진은 선택할 수 없습니다.

작업은 `%LOCALAPPDATA%\StayStudio\jobs`에 저장됩니다. 프로그램을 다시 열고
이전 작업을 선택하면 이어갈 수 있습니다. 이미 저장한 생성 ID와 결과를 재사용합니다.

Drama3 MCP 생성 요청 후 연결이 끊기면 **중단된 작업 이어서 진행**으로 저장된
Story Studio 프로젝트와 블록의 결과를 조회합니다. 유료 생성 요청을 반복하지 않습니다.
이전 브라우저 방식으로 제출해 결과를 확인하지 못한 작업은 Fish History에서 음성을
다운로드하고 **계정 연결 → 중단된 음성 복구**에 장면 번호와 파일을 넣으세요.

## 밖에서 휴대폰으로 사용하기

집 PC에서 StayStudio를 켜 두고, 휴대폰은 Tailscale(개인 VPN)로 그 PC에 접속합니다.
Tailscale에 로그인한 내 기기만 접속할 수 있고 인터넷에 공개되지 않습니다.
영상 생성과 합성은 PC에서 진행하므로 휴대폰 화면이 꺼져도 작업은 계속됩니다.

처음 한 번만 설정합니다.

1. https://tailscale.com/download 에서 PC와 휴대폰에 Tailscale을 설치하고 **같은 계정**으로 로그인합니다.
2. PC에서 StayStudio를 실행하고 **계정 연결**에서 Codex와 Fish를 연결합니다.
   로그인 창은 PC 브라우저로 돌아오기 때문에 **로그인은 PC에서만** 됩니다. 한 번 연결하면 유지됩니다.
3. PC의 PowerShell에서 다음을 실행합니다. HTTPS·MagicDNS 사용을 묻는 링크가 나오면 열어서 허용하세요.
   ```powershell
   tailscale serve --bg 8765
   ```
   출력에 나온 `https://PC이름.xxxx.ts.net` 주소가 휴대폰에서 열 주소입니다.
   이 설정은 PC를 다시 켜도 유지됩니다. 끄려면 `tailscale serve reset`을 실행합니다.
4. **설정 → 시스템 → 전원**에서 절전 모드를 **안 함**으로 바꿉니다. PC가 잠들면 접속되지 않습니다.
5. PC를 켤 때 StayStudio가 자동으로 실행되게 하려면 `Win+R` → `shell:startup`을 열고
   `StayStudio.exe`의 바로 가기를 넣습니다. 바로 가기 속성의 대상 끝에 ` --no-browser`를 붙이면
   PC 브라우저 창은 열지 않습니다. 자동 실행은 Windows에 로그인한 뒤에 시작하므로,
   업데이트로 재부팅되면 PC에서 로그인해야 다시 접속됩니다.

휴대폰에서는 Tailscale 앱에서 연결을 켠 상태로 위 주소를 브라우저에서 엽니다.
**홈 화면에 추가**하면 앱처럼 쓸 수 있습니다. 갤러리 사진을 바로 첨부할 수 있고,
내보내기한 영상은 휴대폰에 저장됩니다. 아이폰은 **파일** 앱에 저장되므로 공유 버튼에서
**비디오 저장**을 눌러 사진 앱으로 옮기세요. 접속이 안 되면 PC가 켜져 있는지,
StayStudio가 실행 중인지, 두 기기 모두 Tailscale이 연결돼 있는지 확인하세요.

Tailscale 무료 플랜은 공식적으로 비상업적 용도 기준입니다. 수익 목적으로 쓴다면
https://tailscale.com/pricing 에서 요금제를 확인하세요.

## 계정과 데이터

로그인은 각 PC에서 직접 진행합니다. 다른 사람의 로그인 폴더를 복사하지 마세요.
Fish OAuth 토큰은 Windows 사용자 계정의 DPAPI로 암호화합니다.
사진/대본은 분석을 위해 Codex로,
선택된 움직임 사진은 Fish로 전송됩니다. UI와 합성은 내 PC에서 실행합니다.

창을 닫아도 실행 중인 프로그램 콘솔은 남을 수 있습니다. 종료하려면 실행 콘솔에서
Ctrl+C를 누릅니다. 동일 포트가 이미 사용 중이면 기존 StayStudio를 종료하고 다시 실행하세요.

## 현재 검증 범위

사진 크롭·자막 미리보기·기존 음성을 재사용한 합성은 유료 생성 없이 검사할 수 있습니다.
새 Drama3 음성과 실제 Fish 움직임 생성은 계정 로그인 및 표시된 가격 승인이 필요합니다.
MCP 무료 견적과 모델·목소리 확인, 중단 복구 및 견적 변경 차단은 유료 생성 없이 검사합니다.
새 음성의 실제 생성·다운로드는 견적 승인 후 검증해야 합니다.
배포 검증 결과와 남은 외부 서비스 검증은 `docs/superpowers/plans/2026-10-08-local-video-studio-progress.md`에 기록합니다.
