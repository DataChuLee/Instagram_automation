# Stay Studio — 친구 PC 사용법

Windows 10/11 64비트에서 사용합니다. 인터넷 연결, ChatGPT 구독 계정,
Fish 패키지 크레딧이 필요합니다. 개발자 API 키를 입력하는 프로그램이 아닙니다.

## 실행

1. `StayStudio-Windows.zip`을 압축 해제합니다. 폴더 전체를 유지하세요.
2. `StayStudio.exe`를 실행합니다. 브라우저에 `http://127.0.0.1:8765`가 열립니다.
3. **계정 연결**에서 ChatGPT/Codex 구독 계정, Fish MCP, Fish Drama3를 연결합니다.
   Codex는 공식 브라우저 로그인입니다. 브라우저가 자동으로 열리지 않으면
   **ChatGPT 로그인 화면 열기** 링크를 누르세요.
   Fish MCP는 브라우저 OAuth 로그인입니다. Drama3는 별도로 열리는 Fish 창에서 로그인합니다.
   Drama3는 `fish.audio`의 일반 사이트를 엽니다. 베타 사이트에서 Google 로그인 시
   `400: origin_mismatch`가 발생하는 것을 확인해 일반 사이트로 변경했습니다.
   PC에 설치된 Chrome(없으면 Edge)의 전용 로그인 창을 엽니다. Google 로그인은 직접 완료하세요.
   로그인할 때는 프로그램이 브라우저를 제어하지 않습니다. 로그인 후 이 창을 닫고
   프로그램에서 계속 진행하세요. 같은 전용 프로필로 저장된 Fish 로그인 상태를 사용합니다.
   Fish 편집기는 버튼 인식을 위해 영어로 엽니다. 이전 자동화 브라우저에서 Google이
   `This browser or app may not be secure`로 차단한 사례가 있어 로그인 단계를 분리했습니다.
   최종 Google 인증 성공 여부는 사용자가 직접 확인해야 합니다.
4. 사진을 첨부하거나 **숙소 링크로 사진 가져오기**에 여기어때 국내 숙소 상세 링크를 넣고
   **이미지 수집**을 누릅니다. 수집이 끝나면 원하는 사진을 골라 **선택한 사진 추가**를 누르세요.
   파일 첨부와 링크 사진을 함께 쓸 수 있습니다. 숙소명과 출처도 작업에 저장됩니다.
   영상에 넣는 사진은 최대 60장, 사진당 20MB, 선택 사진 전체 300MB, 짧은 변 300px 이상입니다.
   후보 사진은 별도로 보관하므로 수집 목록이 60장을 넘어도 전체에서 추천할 수 있습니다.
   **직접 구성**은 선택한 순서를 유지합니다. 사진을 끌거나 화살표로 순서를 바꾸고
   **사진 분석 & 대본 만들기**를 누르세요. **AI 추천 구성**은 전체 후보에서 원하는
   장수(기본 10장, 1~60장)의 사진·순서·이유·대본·움직임을 함께 추천합니다.
   분석 후에도 후보를 추가할 수 있습니다. 후보로 구성을 교체하면 대본을 다시 작성합니다.
5. 필요하면 대본을 수정해 저장합니다. 크기, 글자색, 외곽선, 그림자, X/Y 위치를
   미리보기에서 조절합니다. 기본값은 페이퍼로지 Bold, Y=13입니다.
   글자 크기와 X/Y 위치는 슬라이더 옆 숫자로도 입력할 수 있습니다.
   글자 크기는 28~120의 정수, X/Y는 -35~35의 0.5 단위입니다.
   **움직임 장면 선택**에서 AI 추천을 바꾸거나 원하는 사진만 체크하세요. 수동 선택은
   개수 제한 없이 업로드한 사진 전체를 선택할 수 있습니다. 예를 들어 사진 2·3만 선택하면
   두 사진만 움직이고 나머지는 정지 사진입니다. 자동 추천은 적합한 사진만 최대 3장입니다.
   선택한 사진마다 프롬프트를 따로 입력할 수 있으며 한국어·영어를 그대로 사용합니다.
   **대본·움직임 변경 저장**으로 저장하세요. 견적 요청 시 미저장 변경도 먼저 저장됩니다.
   내레이션과 화면 자막은 따로 수정합니다. **선택한 사진의 세로 크롭**에서 피사체 중심을
   조절할 수 있습니다. 생성 진행 중이거나 제출 결과가 불확실한 동안에는 수정을 잠급니다.
   내레이션 수정은 해당 음성만, 움직임 프롬프트·크롭 수정은 해당 움직임만 새 견적을 받습니다.
6. **크레딧 견적 확인**을 누릅니다. 움직임과 음성의 실제 견적을 확인한 뒤
   **이 금액 사용 승인 & 영상 만들기**를 눌러야 유료 생성이 시작됩니다.
7. 생성이 끝나면 AI 움직임·음성·자막을 포함한 **1080×1920, 30fps 영상 미리보기**에서
   재생·탐색·볼륨을 확인합니다. **확인한 영상 내보내기**를 눌러 결과물을 저장하세요.
   미리보기와 최종 영상은 동일한 영상 파일을 사용하며 내보내기에 새 Fish 호출은 없습니다.
   **완성본**은 자막·내레이션 포함 MP4,
   **영상**은 자막·음성 없는 MP4, **자막대본**은 TXT 및 시간 자막 SRT,
   **음성파일**은 영상 순서와 속도에 맞춘 내레이션 MP3입니다.
   자막·속도·사진 순서만 바꿀 때는 **영상 미리보기 업데이트**를 사용하세요.
   음성을 재사용하므로 추가 생성 크레딧을 사용하지 않습니다. 장면 사이로 사진을 옮기면
   기존 장면의 음성·자막은 유지한 채 사진 배치를 바꿉니다. 사진과 문구가 맞는지 확인하세요.
   **이 음성/움직임 다시 생성**은 같은 설정도 새 결과를 요청하도록 표시하며, 견적 승인 후
   생성합니다. 이전 결과 플레이어와 **결과 복원**, **이전 구성 복원**으로 되돌릴 수 있습니다.
   변경 전 영상은 오래된 미리보기로 표시하고 최신 미리보기가 준비될 때까지 내보내기를 막습니다.

## 영상과 움직임

- 출력은 항상 1080×1920, 9:16, 30fps, H.264 MP4입니다.
- 가로 사진은 피사체 중심으로 세로 크롭합니다. 원본 사진 해상도가 낮으면
  원본에 없는 디테일을 복원하는 효과는 없습니다.
- 움직임은 Fish MCP의 Seedance 2.0, 네이티브 1080p, 4초로 요청합니다.
  AI 추천 기본값은 최대 3장이고, 사용자가 업로드한 사진 전체를 움직임으로 선택할 수 있습니다.
  실제 반환 해상도가 다르면 출력하지 않습니다.
- 적합하지 않은 사진은 움직임 생성 대신 부드러운 확대를 적용합니다.
  생성 클립보다 장면이 길면 마지막 프레임을 유지하며 반복 재생하지 않습니다.
  긴 화면 자막은 최대 두 줄씩 나누어 표시합니다. 실제 길이 25~35초, 사진당 평균 1.5초,
  마지막 사진 1초 기준을 벗어나면 편집 화면에 권장사항을 표시합니다.
- 음성은 일반여성2(ID `4a81bbbb5cd44f22922bf934cb93b369`), Drama3입니다.
  MCP에 모델 선택 기능이 없어 공식 웹 편집 화면을 사용합니다.
- 웹 화면에서 Drama3 모델, 정확한 목소리, 사전 크레딧 가격을 확인할 수 없으면
  생성하지 않고 이유를 표시합니다. 다른 모델로 자동 변경하지 않습니다.
- Y=13은 첨부 화면을 기준으로 화면 중앙보다 13% 위, 즉 1920px 화면에서 약710px입니다.
  VLLO의 내부 좌표 규격을 가져온 것은 아니므로 프로그램 미리보기로 최종 위치를 확인하세요.

## 중단된 작업

링크 수집은 `%LOCALAPPDATA%\StayStudio\collections`에 저장됩니다.
수집용 브라우저 창이 열리고, 수집이 끝나면 닫힙니다. 수집 중에는 해당 창을 유지하세요.
수집을 중단했으면 같은 링크로 다시 수집하세요. 정상 저장된 원본 사진은 재사용합니다.
일부 사진 수집이 실패해도 성공한 사진을 선택해 작업에 넣을 수 있습니다.
현재 링크 수집은 여기어때 국내 숙소 상세 페이지를 지원합니다.
해외 숙소·검색 페이지·다른 사이트 링크는 지원하지 않습니다.
수집 화면에 해상도나 용량 때문에 사용 불가로 표시된 사진은 선택할 수 없습니다.

작업은 `%LOCALAPPDATA%\StayStudio\jobs`에 저장됩니다. 프로그램을 다시 열고
이전 작업을 선택하면 이어갈 수 있습니다. 이미 저장한 생성 ID와 결과를 재사용합니다.

Drama3에서 생성 요청 후 결과를 확인하기 전에 연결이 끊기면 자동으로 재생성하지 않습니다.
Fish History에서 해당 음성을 다운로드하고 **계정 연결 → 중단된 음성 복구**에
장면 번호와 파일을 넣으세요. 생성 전 금액 승인은 음성 복구 권한과 별개입니다.

## 계정과 데이터

로그인은 각 PC에서 직접 진행합니다. 다른 사람의 로그인 폴더를 복사하지 마세요.
Fish OAuth 토큰은 Windows 사용자 계정의 DPAPI로 암호화합니다.
웹 로그인은 전용 브라우저 프로필에 저장됩니다. 사진/대본은 분석을 위해 Codex로,
선택된 움직임 사진은 Fish로 전송됩니다. UI와 합성은 내 PC에서 실행합니다.

창을 닫아도 실행 중인 프로그램 콘솔은 남을 수 있습니다. 종료하려면 실행 콘솔에서
Ctrl+C를 누릅니다. 동일 포트가 이미 사용 중이면 기존 StayStudio를 종료하고 다시 실행하세요.

## 현재 검증 범위

사진 크롭·자막 미리보기·기존 음성을 재사용한 합성은 유료 생성 없이 검사할 수 있습니다.
새 Drama3 음성과 실제 Fish 움직임 생성은 계정 로그인 및 표시된 가격 승인이 필요합니다.
현재 공개 Drama3 편집기에서는 사전 가격 표시를 확인하지 못했습니다.
로그인 후에도 가격이 없으면 전체 자동 생성은 그 단계에서 중단됩니다.
완전한 자동 생성이 검증된 배포본으로 취급하지 마세요.
공식 웹 UI가 변경되거나 사전 가격이 표시되지 않으면 이 프로그램은 생성을 중단합니다.
배포 검증 결과와 남은 외부 서비스 검증은 `docs/superpowers/plans/2026-10-08-local-video-studio-progress.md`에 기록합니다.
