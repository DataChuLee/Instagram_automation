# 한국어 숙소 쇼츠

목표: 숙소를 탐색하는 여행자의 관심과 저장을 유도하는 25~35초 한국어 영상.

1. 사진에서 확인할 수 있는 사실을 먼저 확인한다. 위치·가격·예약 경로·상호·사용 경험은 추측하지 않는다. 시설의 전용/공용 여부도 사진만 보고 단정하지 않는다.
   넓은 수면이 강·호수·바다 중 무엇인지 출처 라벨로 확인되지 않으면 '물 풍경'처럼 중립적으로 쓴다. 사진만으로 조식 제공·무료·온천·전용 시설 여부를 단정하지 않는다.
2. 가장 눈에 띄는 시각적 매력을 첫 문장에 담는다. 객실→핵심 시설→분위기로 자연스럽게 연결하되 직접 구성의 사진 순서를 바꾸지 않는다. 없는 시설은 생략한다.
3. 서로 다른 객실을 하나의 객실로 설명하지 않는다. 라벨이 불확실하면 객실 이름을 붙이지 않는다.
4. 한국어 구어체로 짧게 쓴다. 시설 목록을 기계적으로 나열하거나 '최고', '완벽', '무조건', '가성비'처럼 근거 없는 주장을 하지 않는다. 체험하지 않은 경험담을 쓰지 않는다.
5. 내레이션은 25~35초 낭독을 목표로 한다. 화면 자막은 같은 의미의 짧은 문장으로 쓰고, 하나의 화면에 긴 문단을 넣지 않는다. 마지막은 '다음 여행을 위해 저장해 두세요'와 같은 부담 없는 행동을 제안한다.
6. 사진과 각 문장의 근거, 객실 구분, 표현 반복, 낭독 길이, 자막 가독성을 검수한 후 수정된 최종 결과만 반환한다.
   장면별 내레이션은 공백 포함 150자 이내로 완성하고 마침표로 끝낸다. 긴 문장을 제한 길이에서 잘라 내지 말고, 짧고 완성된 문장으로 고쳐 쓴다. 마지막 장면에는 완성된 저장 유도 문장을 포함한다.

## 움직임

각 사진의 움직임 적합성과 이유를 평가한다. 물결·잎의 미세한 움직임처럼 사진에 실제 있는 요소의 작고 자연스러운 동작을 우선한다. 정지 구도가 더 좋거나 왜곡 위험이 크면 정지 사진을 권장한다.
영어 프롬프트는 움직일 대상·동작·강도와 원본 보존 조건을 구체적으로 적는다. 건물/객실 구조, 가구, 얼굴, 조명, 색, 화면의 요소를 유지하고 새 물체·사람·시설을 추가하지 않는다. 모든 사진에 같은 카메라 이동 문구를 반복하지 않는다.
